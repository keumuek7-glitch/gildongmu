# 서울교통공사 공개 자료 (원본 사본)

`npm run build:subway`가 읽는 원본 자료입니다. 서울교통공사가 만들고 서울시·공공데이터포털이 공개한 자료이며,
공공누리 1유형(출처 표시) / 이용허락범위 제한 없음입니다. **앱 설정 화면에 출처를 표시합니다.**

| 파일 | 내용 | 받은 곳 | 자료 기준일 |
|---|---|---|---|
| `역간거리_및_소요시간_240810.csv` | 역과 역 사이 시간·거리 | 서울 열린데이터광장 OA-12034 | 2024-08-10 |
| `환승역거리_소요시간_20250331.csv` | 환승역 걸어서 갈아타는 거리·시간 | 서울 열린데이터광장 OA-13290 | 2025-03-31 |
| `1_8호선_역사_좌표_20250814.csv` | 1~8호선 276개 역 좌표 | 공공데이터포털 15099316 | 2025-08-14 |

- 받은 날: 2026-11-25. 원본은 CP949(EUC-KR) 글자 묶음이라 UTF-8로 바꿔 저장했습니다(내용은 그대로).
- 첫 두 파일은 서울 열린데이터광장에서 로그인 없이 받아지는 것을 GitHub 서버(해외)에서 확인했습니다. 셋째 파일(공공데이터포털)은 받는 횟수가 많으면 사람 확인(CAPTCHA)이 나올 수 있어, 자주 자동으로 받지 않습니다. 역 좌표는 역이 새로 생기거나 옮길 때만 바뀐다고 안내되어 있습니다.
- 새 자료로 바꿀 때: 같은 이름 규칙(`역간거리`, `환승역거리`, `1_8호선_역사_좌표`로 시작)으로 파일을 넣고 `npm run build:subway` 뒤 `npm test`. 가장 늦은 이름의 파일을 씁니다.
