# 길동무 A 버전 (시제품)

어르신 화면과 가족(자녀) 화면이 한 앱에 들어 있습니다. 처음 열면 "누가 쓰나요?"에서 고릅니다.

## 지금 되는 것
- 어르신: 첫 실행 위치 동의 화면 → 대기 → 가족이 보낸 방향 화면(로드뷰 자리) → 나침반 → 하차 알림(주황) → 도착
- 나침반: 목적지가 늘 위, 내가 아래. 방향이 맞으면(±20°) 화면 전체가 초록 + "이쪽이에요", 아니면 "오른쪽으로 돌아요"/"왼쪽으로 돌아요". 동서남북은 작은 회색.
- 하차 알림: 정류장 이름이 아니라 좌표로 판단. 400m 안 "다음에 내려요", 60m 안 "지금 내려요" (소리·진동). 400m는 임시값, 설정에서 바꿈.
- 가족: 출발·내릴 곳·도착 입력칸, 칸마다 지우기, "모두 처음부터". 목적지가 늘 위로 오게 돌린 약도, 깜빡이는 파란 점선, 어르신이 보는 쪽(옅은 부채꼴).
- 가족이 위치를 볼 때마다 어르신 화면에 "가족이 내 위치를 봤어요" 알림.
- 보내기: 위치 + 방향(각도) + 한 마디. 로드뷰 사진은 보내지 않고 어르신 앱이 그 자리 로드뷰를 직접 띄움. 카톡 링크(카카오맵 로드뷰 링크)도 함께 보낼 수 있음.
- 시험 모드(설정): 가짜 위치·방향 막대로 컴퓨터에서도 흐름 확인.

## 아직 안 되는 것
- 두 휴대폰 사이 연결: 지금은 같은 휴대폰(같은 브라우저) 안의 두 화면끼리만 주고받음. 서로 다른 휴대폰은 작은 서버가 필요(다음 단계).
- 화면이 꺼진 동안 위치 추적: 웹앱으로는 안 됨. 플레이스토어용 안드로이드 앱으로 감쌀 때 해결.
- 로드뷰·장소 찾기: 카카오 키를 넣어야 켜짐. 코드는 넣었지만, 작업 환경에서 카카오 서버 접속이 막혀 있어 실제로 돌려 보지 못함.
- 자녀 목소리 녹음: 빠짐. 대신 어르신 휴대폰이 한 마디를 소리 내어 읽음.
- 예시 경로 좌표는 시험용 가짜 좌표(실제 위치 아님).

## 카카오 키 (코드에 넣지 않음, 앱 설정 화면에 입력)
1. developers.kakao.com 로그인 → 내 애플리케이션 → 애플리케이션 추가
2. 앱 키 중 **JavaScript 키** 복사
3. 플랫폼 → Web → 사이트 도메인에 앱 주소 등록 (예: 넷리파이 주소)
4. 앱 설정 화면 "카카오 JavaScript 키" 칸에 붙여 넣고 저장
(콘솔에 '카카오맵' 사용 설정 항목이 보이면 켜 주세요. 필요한지 여부는 확인 안 됨)
